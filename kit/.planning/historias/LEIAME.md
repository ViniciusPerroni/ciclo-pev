# Histórias

Guarde aqui as histórias de usuário, uma por arquivo (`<slug>.md`), escritas no modelo `.claude/skills/pev-planejar/templates/historia.md`.

A skill `pev-planejar` usa a história como entrada: ela faz perguntas só sobre o que estiver nebuloso. Sem história, faz o questionário completo.

Depois que o plano é criado, a história ganha no topo `**Status:** Planejada (Plano NN)`.
